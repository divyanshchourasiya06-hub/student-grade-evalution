1. Project Architecture & Philosophy

Gradely utilizes a Zero-Dependency Client-Side Reactive Architecture as its primary production engine. The entire operational application is consolidated within a standalone, self-sufficient file (index.html) powered by pure ES6+ JavaScript, semantic HTML5, and responsive CSS3 design tokens.

Architectural Motivations:

  • Instant Cold-Start: Loads in under 15 milliseconds across standard cellular connections with zero backend cold-start delays.
  • Complete Offline Capability: Can run without an active internet connection on standalone desktop or laptop computers.
  • Zero Server Infrastructure Costs: Operates entirely within the user's browser client runtime, enabling free static hosting on cloud platforms like Render.
  • Client-Side Cryptographic PDF Generation: Uses embedded jsPDF modules to compile vector transcripts with custom fonts and seals without requiring server-side Puppeteer or headless Chrome processes.
  • Multi-Tier Extensibility: For centralized enterprise campuses, the project repository supplies a complete reference backend in Node.js/TypeScript with Prisma ORM and PostgreSQL.

6. Mathematical Grading & SGPA Algorithms

The grading engine operates as a deterministic pipeline:

Algorithm 1: Credit-Weighted SGPA

Algorithm ComputeSGPA(MarksList, SubjectsList, OrdinanceScale): TotalWeightedPoints = 0 TotalCredits = 0 FailedPapersCount = 0 For i = 0 to length(SubjectsList) - 1: Subject = SubjectsList[i] Mark = MarksList[i] CoursePct = (Mark / Subject.MaxMarks) * 100 GradePoint = LookupGradePoint(CoursePct, OrdinanceScale) TotalWeightedPoints += (GradePoint * Subject.Credits) TotalCredits += Subject.Credits If GradePoint == 0: FailedPapersCount += 1 SGPA = TotalWeightedPoints / TotalCredits SemesterStatus = (FailedPapersCount == 0) ? "PASS" : "FAIL" Return (SGPA, SemesterStatus)

Algorithm 2: Cohort Ranking with Tie-Breaking

Algorithm RankCohort(EvaluatedStudents): Sort EvaluatedStudents Descending by (Student.SGPA, Student.AggregatePercentage) CurrentRank = 1 For i = 0 to length(EvaluatedStudents) - 1: If i > 0: Prev = EvaluatedStudents[i - 1] Curr = EvaluatedStudents[i] If (Curr.SGPA != Prev.SGPA) OR (Curr.AggregatePct != Prev.AggregatePct): CurrentRank = i + 1 EvaluatedStudents[i].Rank = CurrentRank Return EvaluatedStudents

B. Production Cloud Deployment on Render

Gradely uses Render's Infrastructure-as-Code blueprint system via render.yaml:

services: - type: web name: gradely-academic-portal env: static buildCommand: "" staticPublishPath: . routes: - type: rewrite source: /* destination: /index.html

Deployment Steps on Render:

  1. Sign in to dashboard.render.com.
  2. Click New + → Static Site.
  3. Connect the GitHub repository: divyanshchourasiya06-hub/student-grade-evalution.
  4. Set Branch to main, Build Command to empty, and Publish Directory to . (root).
  5. Click Create Static Site. Render automatically compiles and assigns a permanent HTTPS domain.

8. Security, Error Handling & Integrity Measures

  • CSV Formula Injection Sanitization: Before generating directory CSV exports, the exporter checks every string. If a cell begins with characters such as =, +, -, or @, a single apostrophe (') is prepended to prevent arbitrary command execution in spreadsheet applications.
  • Numeric Boundary Clamping: Client-side input handlers prevent non-numeric entry, negative marks, and scores exceeding course maximums. Invalid inputs trigger immediate red validation outlines and disable SGPA calculation.
  • Safe DOM Injections: All dynamic candidate names and text nodes are sanitized before injection to prevent Cross-Site Scripting (XSS).
  • Audit Trail Integrity: State mutations log timestamped entries in a circular buffer tracking the actor, operation, and modified entities.

Gradely – Complete User Manual

Student Grade Evaluation & Merit Management System (Acadex 2.0)
Applicable for Administrators, Faculty Members, and Students · Version 2.1.0

1. Introduction to Gradely

Gradely (also known as Acadex 2.0) is an all-in-one, browser-based academic evaluation portal designed for autonomous engineering institutions operating under the Choice-Based Credit System (CBCS). It simplifies the entire semester grading cycle, automating:

  • Candidate directory registration and cohort assignment.
  • Curriculum course paper setup with custom credit weightings.
  • Rapid, validated student marks input with instantaneous error checking.
  • Credit-weighted Semester Grade Point Average (SGPA) computation.
  • Automated class rank determination with secondary percentage tie-breaking.
  • One-click certified PDF transcript generation and CSV exports.
  • Tri-State theme switching (Light Mode, Dark Mode, System Default).

2. System Access Requirements

Gradely requires no software installations or plugins. You only need a modern internet browser:

  • Google Chrome (version 90+)
  • Microsoft Edge (version 90+)
  • Mozilla Firefox (version 88+)
  • Apple Safari (version 14+)

5. Admin Dashboard Walkthrough

Upon accessing Gradely as an Administrator, the Academic Dashboard displays 5 live analytical metric cards:

  1. Total Candidates: Total count of enrolled students in the active academic semester.
  2. Evaluated Cohort: Number of candidates whose papers have been fully evaluated.
  3. Class Average: Average percentage across all evaluated students.
  4. Qualification Rate: Percentage of evaluated candidates who have cleared all papers with no remedial backlogs.
  5. Top Cohort SGPA: Highest SGPA achieved by the current class topper.

Below the metrics, two graphical cards illustrate the Grade Distribution (A+ to F) progress breakdown and the Subject Average Breakdown for all curriculum courses, followed by the Class Leaderboard (Top 5 Rankers).

6. How Admin Adds & Manages Teachers

1 In the sidebar under Governance & Access, click User Management.
2 Ensure the Faculty & Teachers sub-tab is active.
3 Click the blue "+ Add Faculty Member" button.
4 Fill in the teacher details:
  • Full Name: e.g., Dr. Alok Verma
  • Teacher ID: e.g., TCH-CS-101
  • Department: e.g., Computer Science and Engineering
  • Assigned Subjects: Check the courses they teach (e.g., CSE101, MTH101).
  • Authorized Section(s): Select CSE-A, CSE-B, or All Sections.
5 Click "Register Faculty Member". The faculty member is now registered and will appear in the Teacher dropdown.

7. How Admin Adds & Manages Students

1 Navigate to Student Directory in the sidebar.
2 Click "+ Add Candidate".
3 Enter the candidate's Full Name, unique Enrollment Number (e.g., 0901CS241021), Section (CSE-A or CSE-B), Department, and Academic Email.
4 Click "Save Candidate Record".
5 The student is automatically enrolled in all active semester subjects with initial blank marks ready for grading.

8. How Admin Manages Subjects & Course Credits

1 Click Subjects in the sidebar navigation.
2 View all 7 active engineering course papers.
3 To add a new paper, click "+ Add Subject". Enter Course Title, Course Code (e.g. CSE102), Course Category (Theory / Practical), Maximum Marks (e.g., 100), and Credit Weighting (e.g., 4).
4 Click "Save Subject". The new course is instantly synced to all student scorecards.

9. Teacher Dashboard Walkthrough

When switching to Teacher View, the sidebar is streamlined to focus on teaching responsibilities. The teacher lands on My Departmental Cohort, displaying:

  • Faculty Profile Banner: Displays active teacher name, Department, and Authorized Sections.
  • Scoped Performance Metrics: Total cohort students, evaluated count, pending evaluation tally, and cohort pass rate.
  • Faculty Selector: Switch between registered faculty accounts to inspect different departmental assignments.

10. How Teachers Enter & Update Marks

1 In Teacher View, locate the candidate row and click the blue "Grade Marks" button.
2 The system transitions to the Marks Entry register with that student selected.
3 In the Marks Scored input column, enter the candidate's marks for each course paper.
4 Instant Validation: If you accidentally type a number exceeding the maximum marks (e.g. 105 in a 100-mark paper) or a negative value, the cell border turns red and flags as INVALID.
5 The system automatically displays the percentage, letter grade (e.g., $A^+$, $B$), grade point, and paper status (PASS or FAIL).
6 Click "Save Evaluation Record" to commit the marks.
Pro-Tip: Teachers can also use the Candidate Selector dropdown at the top of the Marks Entry view to quickly grade consecutive students without leaving the page.

11. How Students View Their Results

1 Switch to Student View via the bottom-left role selector.
2 Select your name from the candidate dropdown to load your personal transcript.
3 Inspect your personal scorecard card showing:
  • Candidate Profile (Name, Roll Number, Department, Section).
  • Total Marks Scored and Cumulative Percentage.
  • Earned SGPA and Overall Letter Grade.
  • Comprehensive course breakdown table with individual grade points.
4 Click "Download Official Transcript (PDF)" to save your certified grade sheet.

Gradely uses the autonomous 10-point Choice-Based Credit System (CBCS):

Remedial Rule: If a student earns an F in any course, their overall semester result becomes REMEDIAL (FAIL) until the backlog is cleared, regardless of high scores in other subjects.

13. Downloading Reports & Official Registers

Gradely provides several institutional export options:

  • Individual Student Transcript (PDF): Available on the Student Portal. Formatted with academic seal, semester credit breakdown, and conferral signatures.
  • Official Class Merit Register (PDF): Click "Export Transcripts (PDF)" in the top header. Generates a comprehensive class tabulation sheet sorting candidates by Rank and SGPA.
  • Candidate Directory (CSV): In the Student Directory view, click "Export Directory (CSV)" to download an Excel-compatible spreadsheet with built-in formula injection sanitization.

14. Switching Between Light and Dark Mode

Gradely includes an integrated theme switcher in the top navigation bar with three options:

  • Sun Icon (Δ): Light Mode – High-contrast crisp paper aesthetic for bright daylit offices.
  • Moon Icon (O): Dark Mode – Subdued navy/slate palette for low eye strain during evening grading sessions.
  • Monitor Icon ([ ]): System Default – Automatically matches your operating system theme in real-time.

15. Common Errors & Troubleshooting

Issue Encountered Probable Cause Solution
Red border around mark input Score is negative or exceeds the maximum marks for the paper. Enter a valid numerical mark between 0 and the subject's maximum marks.
Student result says "Pending" One or more subjects have not had marks entered yet. Complete marks entry for all 7 registered subjects to generate final SGPA.
Cannot see Admin menu links Active user role is set to Teacher or Student. Switch role dropdown in bottom-left sidebar back to Admin View.
Old data showing after browser restart Browser is reading cached state from previous session. The system auto-migrates to acadex_v2_1_store. If needed, perform a hard refresh (Ctrl + F5).
